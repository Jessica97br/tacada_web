🏏 Tacada

Jogo de rebatida estilo críquete/beisebol feito em Python com Pygame. Quanto mais perto a bola estiver do taco no momento do clique, melhor a tacada!

Projeto pessoal criado para aprender mais sobre Python e desenvolvimento de jogos.

🎮 Como jogar
A bola é lançada em direção ao taco.
Clique com o mouse no momento certo para rebater.
Quanto mais próxima a bola estiver do taco no clique, melhor será a tacada.
Teste seus reflexos e tente fazer a melhor pontuação!
Controles
Ação	Tecla / Botão
Rebater	Clique do mouse
🚀 Como rodar

Pré-requisitos: Python 3.8+ instalado.

bash
# 1. Clone o repositório
git clone https://github.com/Jessica97br/tacada_web
cd tacada_web

# 2. Instale o Pygame
pip install pygame

# 3. Execute o jogo
python main.py
